Riva 的观赏长度/吃水为 2.4 / 0.11 米，MAVERICK GT 为 2.6 / 0.10 米。这些是展示设定，不是实体船规格。两艘船分别保留木质游艇与现代运动艇的材质特点；增加船型必须重新量测朝向、水线、尺寸并验证接触效果。泊位对齐只解决路线与码头锚点的位置/方向关系，不能保证任意码头变换后仍避开岸景，既定岸线和镜头安全范围仍需一起验证。

首次进入继续从前景巡游开始。用户换船时，新模型先在渲染场景外准备，原船保持可见；只有最新成功请求可替换船体、接触和镜头尺寸，新船进入泊位停 4 秒后再出航。失败保留原船并显示重试，加载期间可以改选另一艘，过时或取消的结果不落入场景。暂停、氛围、镜头和水声选择保留；新旧模型不会作为两艘巡游船同时展示。

## 画面与空间

青绿色的浅海湾、晒旧的木栈桥、一处帆布遮阳的临水休息区。主船缓慢经过前景，湾口留出海平线和远山。主要感受是明亮、松弛、有人照料过的船模小天地。

- 近景：少量水下石块、沙底与浅水光纹，保留可辨认的深浅变化。
- 中景：木质快艇和靠泊位；码头从侧面伸入，形成自然的观赏边框。
- 远景：低矮岩岸围出湾口，海平线和淡远山提供开阔感。
- 水面约占主画面的六成；岸景密度集中在码头一侧。巡游主视角始终保留完整船体、接触水面的位置和尾流。
- 竖屏重新取景：船处于中央可视区域，码头保留局部，底部操作不压住船。

活动水域建议约 22 × 18 米，远海与山体作为视觉背景。初稿提出约 1.1 米的尺度；实现中将 Riva 按 2.4 米观赏尺度挂载，以保留木纹、座舱和水线的可辨认细节。模型原始船首实测为 +X，通过独立挂载层对齐 -Z，默认吃水 0.11 米（可配置）。岸边长椅、救生圈和木板尺寸建立稳定的比例参照。

主光照为温暖但清透的午后；另有低角度日落和蓝调暮色。所有时段一起调整天空、主光、环境光、雾、水色和曝光，不仅切换背景颜色。

## 一轮观赏

实现采用 90 秒连续航行与 18 秒靠泊，共 108 秒一轮；打开时从前景经过开始，循环顺序为：

1. 在靠泊位轻轻起伏，先看到船体木纹与金属细节。
2. 缓慢离开码头，尾流逐步出现。
3. 沿浅滩划过弧线，侧面展现船身与清水。
4. 进入开阔湾心，岸边固定镜头观看它经过。
5. 转入码头的安全接近线，持续减速，平稳入泊。
6. 停留约 18 秒，尾流消退；水面、船体轻摆与水声继续，再进入下一轮。

巡游是连续、可中途暂停恢复的状态过程，不通过位置跳变接回起点。停泊只改变船的运动，不冻结整个环境。航线避开码头、浅滩露石和岸边，并为不同尺寸船艇保留余量。

## 镜头与操作

提供五种镜头选择；四个具体机位组成自动观赏：

| 镜头 | 观看内容 | 约束 |
| --- | --- | --- |
| 自动观赏（`auto`） | 从船侧近观开始，依次经过码头定机、贴水侧跟和湾心斜览 | 每个机位停留后慢过渡，不与 108 秒航线强制同步 |
| 船侧近观（`waterline`） | 低机位观察侧舷水线、船边水面与近端尾迹 | 固定世界方向跟随；桌面开场船宽约占 45%，竖屏退远保留整船，转向时不绕船旋转 |
| 码头定机（`scenic`） | 船从泊位出发，经过观赏区，再返回 | 船在镜头内的行程需经过实测，避免长时间空镜 |
| 贴水侧跟（`follow`） | 船身、木纹、尾流与水面接触 | 保留完整船体，镜头不得穿入码头或岩岸 |
| 湾心斜览（`overview`） | 海湾轮廓、码头组合和巡游路线 | 控制高度，使船仍可辨认 |

自动切换采用慢过渡；可以锁定一个视角。减少动态效果仍从暂停的码头定机开始。复用现有暂停、水声、拍照和沉浸操作。声音以细小拍岸声为主，停泊时保留轻微水声；首次仍由用户点击开启。

## 2026-10-04 船水接触与近观镜头

本次把船水接触拆为独立 `src/scene-assets/boat-water-interaction/` 资产。入口 `createBoatWaterInteraction({ length, beam, draft, sampleSurface })` 不拥有场景、renderer、RAF 或船模型；晴湾传入 `sampleSurface: water.sampleSurface`，并通过 `water.setInteraction(interaction)` 绑定水面数据。CPU 浮态与 GPU 环境涌浪共用同一波谱，当前浪幅同步来自水面；局部船边起伏、法线和尾流由水面 shader 追加。

每帧先更新导航，然后依次调用：

```js
water.update(time, boat);
interaction.update(dt, time, boat);
boatVisual.update(dt, time, boat, interaction.pose);
```

`interaction.pose` 的 `heave`、`pitch`、`roll` 驱动船体，不再用与水面无关的正弦起伏作为晴湾默认浮态。吃水继续由船体挂载层处理。重置时先恢复导航和水面时间，再调用 `interaction.reset(time, boat)` 消除旧尾迹，并立即将新姿态应用到船体。关闭时分别释放 water、interaction 和 boatVisual，外部 renderer、相机与帧循环仍由宿主拥有。可复制的独立接入例子见 [观赏资产接入](VIEWING-ASSETS.md#独立接入船水接触)。

晴湾的水面 shader 内尾流已替换此前的 `shared/viewing/wake.js` 网格；湿地继续使用旧尾迹，行为不因这次接入改变。`waterline` 船侧近观用于暴露水线和近端尾迹细节，并作为自动观赏的第一镜头；原有 `follow`、`scenic`、`overview` 仍可单独选择。

这是第一版小尺度实时近似，针对当前 2.4 米观赏船和缓慢巡游调校，不是完整流体求解，也不表示视觉已达到最终品质。本次验收见下方独立记录，不沿用上方较早版本的四镜头验收结论。
